Integritet och data

Ritningar och protokoll stannar på din enhet. Tillsynos server sparar bara ditt konto: namn, e-post och vilka moduler du har tillgång till. Senast uppdaterad 7 november 2026.

Tillsyno skickar inga ritningar eller protokoll till någon server. Textigenkänning (OCR) görs på enheten. Appen har ingen statistik, reklam eller spårning.

Vem som ansvarar

Den organisation som har gett dig ditt konto, oftast din arbetsgivare, ansvarar för uppgifterna om dig och om kunderna i protokollen. Tillsyno behandlar kontouppgifterna för deras räkning. Underleverantörer är Supabase (konton, EU) och GitHub (webbsidan).

Dina rättigheter

  • Du kan få veta vilka uppgifter som finns om dig, få dem rättade och få kontot raderat. Kontakta din administratör.
  • Administratören kan radera kontot helt. Uppgifter på din enhet raderar du själv med Logga ut eller Rensa enhetens data i Mitt konto.
  • Du kan klaga hos Integritetsskyddsmyndigheten (imy.se).

Lagring i webbläsaren

Appen använder webbläsarens lagring för inloggningen och för att arbetet ska fungera utan internet. Den lagringen används inte för spårning.
