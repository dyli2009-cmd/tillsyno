# CE TEST 56 – större och tydligare underskrift, mindre datum

- Projektuppgifternas förhandsvisning ger underskriften större yta och datumet mindre text, centrerat under.
- Vid redigering av original-PDF:er utökas signaturens andel av befintligt signaturfält från ungefär 70 % till ungefär 80 %, med datumrad sänkt till ~5–7,5 PDF-punkter. Ingen fältyta flyttas.
- Signaturens blå färg i exporterad PDF får högre kontrast, datumet blir diskretare. Bildförhållande och ursprunglig signaturform bevaras.
- Inga ändringar i projektdata, signaturdata, signaturens lagring, datumformat, mallar eller glas-/utan-glaslogik.
- Alla ändringar gäller nya PDF-exporter; redan sparade PDF-filer ändras inte förrän de skapas igen.

QA: Controller + module syntax, databasnycklar, befintliga fält/ID:n, versionslänkar och offlinecache kontrollerade. Visuell PDF-granskning på riktig iPad återstår.
