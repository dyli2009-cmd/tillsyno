# CE-märkning TEST 23 – en gemensam projektunderskrift

Projektuppgifter → Projektunderskrift används nu direkt för underskriftsfält i CE-dokument på alla dörrar (Med glas / Utan glas). PDF-editor visar signaturbilden i Sig-widgetar, textwidgets som heter Underskrift/Signatur/Namnteckning och Riskanalysens fasta signaturruta. PDF-exporten använder samma projektunderskrift även om det finns äldre individuellt sparade signaturbilder; ändras projektunderskriften används den nya automatiskt. Egenkontrollens punktvisa 10.5.x Signatur fästs endast där kontrollpunkten har ett aktivt val (fabriksförvalda val räknas). Loggbokens framtida service-/underhållsposter försigneras inte. Har projektet ingen gemensam underskrift behålls äldre manuella signaturer.

Sparningen fortsätter att använda det befintliga projekt-PDF-flödet, inga nya datatunga kopior skapas. Syntax för JS och signaturval under simulering verifierade; full visuell test på iPad/iPhone med originalmallar återstår.
